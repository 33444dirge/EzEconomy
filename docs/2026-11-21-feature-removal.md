# 银行、每日登录奖励与货币兑换移除

当前目录为 `D:/桌面/JiuJiu/EzEconomy`，分支为 `jiujiu`。

本次删除以下功能的运行逻辑，而非仅关闭配置开关：

- 银行账户创建/删除、存取款、成员、利息、入服自动开户、银行 GUI、占位符、银行事件、银行 DTO 和 SQL/文件/MongoDB 存储实现。
- 每日登录奖励、冷却记录、奖励文件、消息/音效、管理重置命令与相关管理器。
- `/currency convert`、汇率图搜索、换算取整、兑换统计，以及普通转账/群发付款中依据收款人偏好自动兑换和显示等值金额的逻辑。

相关命令注册、补全、权限、默认配置、翻译、当前功能/API 文档和旧功能测试一并清理。历史检查报告与变更记录保留历史事实；本文件描述当前版本。

## 仍保留

- 钱包余额、充值扣款、普通转账、群发付款、余额榜、交易记录、消费账本与关联退款。
- 多个相互独立的货币余额、格式与偏好设置。`/currency [currency]` 只改变展示偏好，不移动资金；付款始终按付款指定货币原币入账，收款人偏好不改变货币种类或金额。
- Vault `Economy` 要求实现的银行方法仅返回 `NOT_IMPLEMENTED`，`hasBankSupport()` 固定返回 `false`，银行列表为空。没有银行存储调用或开户逻辑。

## 数据与兼容性

不主动删除服务器现有数据库表、集合、YAML 文件或玩家余额。新版本不再创建或使用银行表、登录奖励文件；旧配置里的相关开关和汇率无法恢复已删除功能。

内部 `StorageProvider` / `EzEconomyAPI` 的银行方法、银行事件/DTO 和兑换工具类已移除，调用这些接口的扩展需要同步调整。普通钱包和消费账本接口保留。替换插件 JAR 后完整重启服务器。
